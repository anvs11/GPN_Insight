## Context and Orientation


React/TypeScript/Vite находятся в frontend; единый API слой — frontend/src/api.ts. Старые TopicDetail/SourceViewer/DecisionForm/ReviewPanel сохраняют работающие мутации с version. SQLite v4 и Repository в backend/app содержат источники, partial результаты, оценки и историю. Новые read DTO/маршруты живут отдельно в workspace_schemas.py/workspace_api.py; приложение остаётся одним процессом, импорт/prompts/replay ключи не меняются. Новый архив требует аддитивной миграции v4→v5 с backup и сохранением всех старых таблиц.

## Plan of Work


Сначала добавить компактный paginated read API для двух представлений, используя один SQLite snapshot. Обращения берутся из реестра, включая не попавшие в темы. Оценки берутся только из актуального пригодного анализа; unknown и отсутствие оценки различаются. Подсчёт и фактические связи задаёт сервер, фильтрация не изображает качество живой модели.

Затем заменить оболочку App: боковая навигация, мониторинг, инструменты импорта и обработки, панели подробностей. Сохранять компоненты смонтированными при смене страницы, чтобы черновики не исчезали; не показывать закрытые панели через accessibility tree. Диалог поддерживает Escape, возврат фокуса и блокировку закрытия при бизнес-записи. CSS/иконки локальные, без CDN/новых зависимостей.

Для отчётов выделяются максимум 30 объектов с точными версиями; ручные title/summary/comment не меняют бизнес-решений. Снимки immutable, устаревшая версия — 409. Архив в SQLite без автоудаления; Markdown/JSON/просмотр/печать/прямой PDF раздельны. backend/app/report_pdf.py использует закреплённый Pillow/системный шрифт: растровый A4 до 30 страниц, без сети, явный отказ вместо обрезания. backend/app/weekly_archive.py сохраняет завершённую календарную неделю в понедельник 00:00 МСК при работающем сервере, проверяет каждые 30 секунд; при старте после простоя — только последнюю неделю, по фактическому состоянию данных. Проверка и запись — одна SQLite transaction; готовый снимок той же недели/режима исключает автоматический дубль. Worker останавливается с lifespan. GET /api/v1/reports/weekly-schedule показывает next_run_at/last_error; настройка APP_WEEKLY_ARCHIVE_ENABLED=true по умолчанию. Отправка Telegram/Макс и корпоративный доступ отложены. Карта показывает реальные связи, не семантическое расстояние.

## Idempotence and Recovery


Перед миграцией v4 существующая БД получает SQLite backup. Рабочие базы не запускать ради тестов. Архив append-only, одинаковый snapshot не создаёт дубль, ошибки записи откатываются. Ничего не удалять и не публиковать без нового поручения. При недоступном browser host честно отделить HTTP/jsdom от визуального теста.

## Surprises & Discoveries


Исходный GET /topics отдаёт полные карточки без реестра всех источников; выводить «Обращения» только из тем нельзя — исчезнут неразобранные/необработанные. Исходный weekly был только по запросу; уточнение пользователя добавило расписание с явной зависимостью от работающего сервера. Topic.status не является статусом закрытия исходного тикета. PDF без нового пакета возможен через Pillow, но он растровый: Markdown/JSON остаются текстовыми экспортами. Computer Use остановил попытку из-за неопределённого URL Edge, визуальная приёмка не приписывается тестам.

Partial источник может иметь requires_analysis=true для retry и уже валидную оценку успешного контекста. Нельзя превращать его в «ещё не обработано» и прятать категории; отдельно показываются state=partial и pending. Source.version не меняется при дополнении распознавания: revision карточки включает текущие processing result ID, поэтому подборка старого контекста получает 409. Existing migration tests строили v2/v3 из свежей базы; для достоверной старой фикстуры они теперь удаляют и новую таблицу архива, а не допускают её неявное существование в старой версии.

Поле implemented_at сервер может вернуть в UTC, хотя UI отправляет Москву: подтверждение сравнивает моменты времени и дополнительные поля истории. Обязательные текстовые поля сервер обрезает по краям; клиент также нормализует их перед PATCH. Browser Use снова вернул The browser access host is unavailable; обход не выполнялся.
