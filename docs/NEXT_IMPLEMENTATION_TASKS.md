# Что осталось до корпоративного внедрения

Основной локальный сценарий пилота реализован. Текущие команды запуска, API,
демонстрационные данные и ограничения описаны в [MONITORING_WORKSPACE.md](MONITORING_WORKSPACE.md).

## Проверки перед передачей

- Визуально пройти импорт, обработку, источники/медиа, решение и экспорт отчёта.
- Проверить обе палитры, список и колонки обращений на рабочих разрешениях.
- Повторить проверки итогового коммита и подтвердить сохранность решений после рестарта.
- Согласовать текст решения, Markdown с метриками/промптами, презентацию и демонстрацию.

## Границы внедрения

- Подключить настоящие внутренние Qwen 3.8, Qwen-ASR и Qwen-VL после согласования протоколов, квот и доступа.
- Оценить качество на независимо размеченных данных и измерить активное время анализа. Replay этого не подтверждает.
- Проверить целевой поток 400–480 обращений в день нагрузочным испытанием.
- Реализовать корпоративные права, получение изменений из системы обращений и доставку отчётов получателям.
- При расширении добавить справочник продуктов и подтверждаемые межканальные связи инцидентов. Сейчас пилот работает с «Вебнефтью» и считает записи источников.

хранение — [STORAGE.md](STORAGE.md), методика эффекта — [EFFECT.md](EFFECT.md).
